# Side-by-Side (SxS) Preference Rubric

Compare **Response A** and **Response B** for the same prompt.

## Preference scale
| Score | Meaning |
|---|---|
| A+++ | A is much better: B has a critical failure A does not |
| A++ | A is better: clear, meaningful advantage |
| A+ | A is slightly better: small but real advantage |
| = | About the same: differences are trivial or cancel out |
| B+ / B++ / B+++ | Mirror of the above |

## Procedure
1. Rate each response on the single-response rubric first.
2. Identify the **deciding factor**: the single most important difference.
3. Choose the preference strength based on how much that factor matters **to the user**.
4. Write a rationale that states the deciding factor in the first sentence.

## Common pitfalls
- **Length bias:** longer is not better if the extra content is padding or off-topic.
- **Formatting bias:** headers and bullets don't fix a wrong answer.
- **Position bias:** read B as carefully as A; swap the order mentally if unsure.
- **Tone over substance:** a confident wrong answer is worse than a hedged correct one.
